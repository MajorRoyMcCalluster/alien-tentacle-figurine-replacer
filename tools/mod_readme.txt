============================================================
A figurine replacer for No Man's Sky. Replaces the Tentacled Figurine cockpit adornment
with a glowing alien tentacle on a suction-cup foot. The top half wobbles with your ship,
glowing rings run up its length, and the item is renamed "{item}" in game.

INSTALL
  1. Extract the "{folder}" folder into:  No Man's Sky\GAMEDATA\MODS\
     (create the MODS folder if it doesn't exist)
  2. Install the Tentacled Figurine in your starship's inventory and look at your dashboard.
     (The figurine is the Phase 5 reward from Expedition 15: Aquarius, which also ran as a
     Redux in January 2025. You need to own it for this mod to show.)

UNINSTALL
  Delete the "{folder}" folder. Nothing is saved to your game, so it's safe to remove any time.

COMPATIBILITY
  - Visual only. Your save is never changed.
  - Multiplayer safe: other players see the normal Tentacled Figurine.
  - Conflicts only with other mods that replace the Tentacled Figurine (OCTOBOBBLEHEAD) model.
  - Works alongside other figurine mods for different figurines.
  - The new name is in English and US English; other languages show the original name.
  - A future game update that changes the Tentacled Figurine may need a mod update.

FILES
  MODELS\...\BOBBLEHEADS\OCTOBOBBLEHEAD.*          new model (geometry + scene)
  MODELS\...\BOBBLEHEADS\OCTOBOBBLEHEAD\ATF_*      materials
  TEXTURES\...\PROPS\ALIENTENTACLE\ATF_*          textures
  LANGUAGE\NMS_LOC9_*.EXML                        item name and description
